# 动作与互动语言设置

右键宠物 → 设置 → 动作与互动语言。所有人物共用，换人物后台词不丢失。

1. 选择动作与姿势、互动与心情、投喂反应、情绪表情或离线聊天，选具体分组；搜索可以快速找到动作或食物。
2. 每行填写一句，事件发生时随机选用并避免紧邻重复。每组 1–100 句，每句最多 180 字符。
3. 「预览台词」显示第一句，并替换 `{name}` 为当前人物名字、`{food}` 为对应食物；宠物空闲时同步显示气泡，不保存修改。
4. 「保存本组」即时生效。切换分组保留草稿，可编辑多组后「保存全部修改」；关闭设置前请保存。
5. 「填入默认」只改当前草稿；检查后再保存，不会恢复或覆盖其他分组。

摸头、戳肚子、投喂、连续同款、夸夸、逗逗、打瞌睡、唤醒、提衣领、落地、趴任务栏、倒挂和窥探都使用各自分组。心情好的摸摸和不同心情的发呆也可以单独设置。

情绪表情分组用于手动菜单或动作预览。互动仍优先使用对应玩法台词；手动移动会显示移动台词，自动漫游保持安静。离线聊天按现有话题选择分组；这里修改的是本地文案，云端 AI 回复与性格仍由「聊天与人格」配置。

文案保存在本机数据目录的 `dialogue.zh-CN.json`。已有自定义会保留，软件新增分组从默认文案补齐。保存前整体验证，错误输入不会造成部分分组写入；设置页保存也保留其他有效的文件编辑。默认有 51 个分组、240 条台词。它们不包含 API Key，也不进入其他用户的安装包。

界面与数据分层参考 [Petra](https://github.com/Wumiu/Petra) 和 [VPet](https://github.com/LorisYounger/VPet) 的桌宠配置组织，在现有 Electron 设置中心中扩展。

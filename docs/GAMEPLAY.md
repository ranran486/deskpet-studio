# 离线互动、姿势与特效

蓝鲸新增八种同画风表情，与事件联动：摸头害羞、戳肚子开心、投喂喜欢、钻石惊讶、连续三次同食物无语、逗弄随心情生气或晕鱼、空闲瞌睡。图集目前 37 帧，四帧挣扎交替播放；源图和生成提示词保留在角色包，内测包只携带运行图集。

头顶按住约 650ms 或轻抚会触发摸头，身体下部单击触发咯咯笑。双击打开五种食物面板：小鱼干、小蛋糕、棒棒糖、团子、钻石；钻石是收藏奖励，不作为食物描述。右键菜单可以夸夸、逗逗、喂食或打开聊天。心情 0–100，影响反应与文案；互动有冷却，投喂按钮短暂去抖。

90 秒无人互动会打瞌睡并显示 zzz；触碰惊醒，装作没睡。全屏安静、隐藏、拖拽、聊天等状态暂停后台干扰。主动姿势不会冒充用户互动重置睡眠计时。底边趴任务栏上沿，身体被遮住，头和手露出；顶部用脚部挂点贴屏幕顶边，气泡在角色下方；左右窥探。停留 7–16 秒，离开后冷却 12–30 秒，避免反复卡在边缘。仍保留完整蜷缩睡眠预览。普通姿势按屏幕地面约束，底部趴姿允许隐藏身体，离开后恢复。

爱心、星星、笑声和 zzz 使用本地 DOM/CSS 粒子，拖拽、情绪与姿势配专属短台词。`assets/dialogue.zh-CN.json` 含 240 条默认文案；可在设置「动作与互动语言」中按组编辑并即时保存，所有人物共用。用户数据目录的同名文件仍保留。选择本地聊天或未设置 Key 时使用关键词回复，显示「本地文案回应 · 无需 API」。不会编造实时知识，也不会请求付费接口。

玩法参考用户提供的 [GenhuiC-sudo/11](https://github.com/GenhuiC-sudo/11)，这是单次提交的 Python/PySide 原型。复用互动、重复食物、心情和姿势思路，按当前 Electron 架构实现，保留其 MIT 许可；没有移植整个 Python 程序。成熟工程对照使用 [Petra](https://github.com/Wumiu/Petra)、[VPet](https://github.com/LorisYounger/VPet) 与 [pixi-live2d-display](https://github.com/guansss/pixi-live2d-display)。

# 下一步开发路线

## 当前边界

本阶段交付可运行框架与完整动作接入。蓝鲸拥有 23 帧图集，身体动作和情绪由统一协议驱动。PSD 导入能输出分层模型，并按骨架与图层语义接入相同动作；精细效果取决于素材拆分质量。

PSD 的 Canvas2D 仍采用整层仿射变换；Live2D 已通过 PixiJS + 官方 Core 真正渲染网格，官方日和为默认测试模型。DeepSeek 设置、可编辑性格、文字口型与回复表情已接入。语音、长程记忆、日记、音乐驱动和安装包尚未实现。

日和缺少蜷缩和提衣领悬垂的专用绑定，使用闭眼、轻摆等回退；统一行为协议已共享，具体全身变形不能跨模型无条件继承。新增模型使用标准参数即可继承视线、情绪与口型；非标准参数与专属动作映射是下一阶段扩展点。环境与制作流程见 LIVE2D-SETUP.md。

## 可直接沿用的接口

| 扩展 | 入口 | 约束 |
| --- | --- | --- |
| 新角色 | `packs/` 或 `plugins/`，`plugin.json` | skin 包声明图集、rig 或 live2d；参数与原生动作按能力回退 |
| 手绘动作 | `states.json` + `atlas.json` | 同一动作各帧保持相同尺寸和脚底锚点；动作包帧名须在当前图集中存在 |
| 新渲染器 | `src/renderer/skinview.ts` | 实现 load/start/stop、alphaAt、react/talk/drag/setLook、setBehavior 与 geometry；命中、聊天、互动继续共用 |
| 聊天供应商 | chat 数据包与 `configSchema` | 设置页自动生成字段；网络和密钥留在主进程 |
| 桌面小工具 | behavior JS 包或声明式触发器 | 使用权限网关、私有 storage、统一宿主命令 |
| 语音 | 主进程服务 + IPC + 渲染端播放 | 后续增加 provider 契约与停止／错误／流式生命周期 |

## 建议实施顺序

1. 美术升级。为蓝鲸制作眼白、瞳孔、闭眼、嘴型、前后发、脸、身体等独立图层，或绘制挥手、走路、睡眠动作帧。保留三视图包作为回退。
2. 动作与渲染。Live2D 已复用成熟渲染器、原生物理、参数限幅和平滑与拖拽／休息优先级；后续增加角色参数别名、动作组映射、精细全身绑定、跨动作过渡与视觉回归。
3. 对话体验。接实际服务验证长流、中断、重试；增加独立历史面板、人格档案，随后扩展 TTS。当前历史只在内存，配置中的 API key 保存于本机文件，未来可接系统加密存储。
4. 常驻体验。隐藏暂停、待机降帧、托盘与 Alt+P 已接入。继续完善快捷键自定义、开机自启和跨 DPI 显示器测试；单机显示器验证不代替多屏实测。
5. 发布与维护。增加版本迁移、导入包编辑／删除 UI、安装包与更新流程、跨版本插件 SDK 测试。将真实角色 PSD 作为视觉回归样本。

每一步继续运行 `npm test` 和 `npm run selfcheck -- --no-sandbox`。GUI 自检使用独立数据目录；运行时生成物和密钥不进入源码包。

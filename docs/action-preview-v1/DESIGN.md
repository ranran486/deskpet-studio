# 蓝鲸动作预览与统一动作模型

此文记录最初的设计预览。2026-10-09 已完成正式桌宠接入：全屏拖动、三侧边缘姿势、提衣领悬垂、移动、情绪及简化气泡均已进入运行时；实现与验证结果见 `../LIVE-ACTIONS-REVIEW.md`。

## 已设计的动作

| 身体动作 | 支点与运动 | 屏幕表现 |
| --- | --- | --- |
| 移动 | 脚底接触点；左右腿交替、头轻微起伏、手臂反向摆动 | 沿移动方向切换朝向，停下后缓慢回到站姿 |
| 下边缘睡眠 | 蜷缩侧卧，双手靠近脸，膝盖收拢，长发自然铺开 | 身体沉入屏幕外，闭眼的上半张脸和部分额发露出，保留缓慢呼吸 |
| 左右边缘窥探 | 腰部与墙边手掌作为稳定部位，头侧倾，眼睛观察、间歇眨眼 | 半身藏在屏幕外，头与手探出；左右使用同一动作的镜像与朝向参数 |
| 提衣领拖拽 | 鼠标固定在后衣领抓点；头低垂、肩膀放松、手腕和脚尖自然下垂 | 衣领先动，身体跟随，长发与衣物滞后；停下后摆动衰减 |

喜怒哀乐另外定义为表情层。高兴表现为笑眼与轻轻弹动，愤怒为皱眉和鼓腮，悲伤为垂头和低垂眼神，平静用于自然呼吸与观察。预览中的四张情绪关键姿态供美术评审，动态表情通道独立于身体状态。

## 跨人物继承

`src/shared/action-model.ts` 提供角色无关的协议与动作采样原型。

1. 动作层保存语义动作、归一化关节姿态、时间、支点和表情参数，不引用蓝鲸专属图片帧名。
2. 角色适配器保存该人物的骨架绑定、图层槽位、衣领抓点以及可用表情部件。
3. `retargetSkeleton` 根据新人物的绑定骨长重定向动作方向。长腿、短手、大小头等不同身材不直接沿用前一个人物的坐标。
   衣领抓点单独映射为衣物支点，不把可伸展的衣领当成一根固定长度的人体骨骼。
4. 渲染器消费重定向姿态。rig 模型按图层或网格驱动；精灵图按语义映射到人物自己的动作帧；单张图使用整体变换回退。

同一动作库能继承时间、支点、摆动、优先级与情绪参数。精细动作的继承仍需要新人物具备相应骨架／图层。单张静图无法直接产生独立的手、脚、口型；四足宠物等骨架拓扑不同的模型需要对应的适配器和姿态变体。

预览中「统一骨架」显示动作结构；「不同身材重定向」改变骨架比例，验证同一动作可保持新模型的骨长。角色图片本身仍是蓝鲸专属关键帧，不代表换一个 PNG 就能自动继承所有精细姿势。

## 行为模式

建议下一阶段采用分层状态机。

| 层 | 内容 | 切换规则 |
| --- | --- | --- |
| 身体 | 拖拽、落地过渡、边缘待机、行走、普通待机 | 拖拽优先；松开后先完成回落／稳定，再恢复自主行为 |
| 表情 | 平静、高兴、愤怒、悲伤、困倦、说话口型 | 可以叠加；短情绪保留一段时间后淡回平静，困倦与说话避免冲突 |
| 次级运动 | 头发、衣物、手脚的滞后和摆动 | 接收主动作速度、加速度；使用阻尼，不自行抢占主动作 |
| 自主意图 | 观察、轻步漫游、休息、短互动 | 用有冷却的加权行为；同类连续出现时降低权重 |

动作过渡先使用 120–250ms 混合，呼吸周期约 3.6s，窥探眨眼周期约 4–6s，拖拽摆角约束在 ±16°。这些均为初始设计参数，需在真实模型上调节。

不要随机频繁出现强烈愤怒或悲伤，也不把用户日常操作推断成负面情绪。情绪可由用户显式选择、角色互动或有明确原因的事件触发。免打扰时减少自主语言和运动。

## 全屏拖动的接入位置

现有 `src/main/window.ts` 以舞台窗口和工作区限制拖动，舞台包含气泡留白，角色因此无法触及部分屏幕边界。

实现已采用显示器 `bounds` 与角色本体／抓点计算：按鼠标所在显示器选择屏幕，允许透明舞台部分离开屏幕，让角色抓点可以到达屏幕所有坐标；任务栏占用空间与普通漫游范围分开处理。

正式窗口已同步角色局部矩形，待机循环给拖动让路，边缘状态进入统一动作驱动；真实窗口四角可达与抓点偏差已经自检。副屏负坐标有纯逻辑覆盖；跨显示器 DPI 仍需要多屏实测。
